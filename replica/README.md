# Flujo de réplica

Orden: recon → architect → design → build → backend → test → diff → entrepreneur → build (mejoras) → brand → launch → deploy.

Cada skill (`/replica-recon`, etc.) está en `.claude/skills/` y deja sus notas en la carpeta `replica/` del proyecto donde la uses.
Instalación global: `./instalar-skills.sh`. Empieza con `/replica-recon` y el nombre del producto.
